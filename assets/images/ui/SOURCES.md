## Downloaded Reference Pack

I also downloaded Kenney UI Pack as a free CC0 reference/source pack:

- Source: `https://kenney.nl/assets/ui-pack`
- License: CC0 1.0 Universal
- Local archive: `_downloads/kenney_ui-pack.zip`
- Extracted folder: `_downloads/kenney_ui-pack/`

Kenney assets are safe to use in commercial and non-commercial projects. If you choose a better button or panel from the extracted pack, copy it into this folder and rename it to the required file name.
