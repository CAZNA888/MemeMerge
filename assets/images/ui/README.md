# UI Images

Здесь лежат PNG-изображения для интерфейса: валюты, кнопки, карточки, панели и фоны.

Общие требования:

- формат: PNG;
- иконки: лучше `128x128 px`, можно `256x256 px`;
- фон у иконок: прозрачный;
- стиль: мультяшный, яркий, читаемый, похожий на мобильную arcade/merge игру;
- без текста внутри иконок, текст будет рисоваться отдельно в игре;
- не использовать просто черные или белые квадраты, если это не временная заглушка;
- объект должен быть по центру и иметь небольшой внутренний отступ.

## Валюты и игровые параметры

### `coin.png`

Иконка монеты.

Что искать:

- золотая монета;
- круглая монета;
- можно с бликом, звездой или буквой, но без мелкого текста.

Параметры:

- `128x128 px`;
- прозрачный фон;
- основной цвет: желтый / золотой;
- используется рядом с числом монет.

### `cup.png`

Иконка кубков / трофеев.

Это НЕ обычный черный или белый куб. В игре "кубки" означают трофеи/очки рейтинга.

Что должно быть:

- трофейный кубок;
- золотой или синий кубок;
- маленький призовой trophy.

Параметры:

- `128x128 px`;
- прозрачный фон;
- должен хорошо читаться рядом с числом;
- используется в верхней панели, наградах и лидерборде.

Что искать:

- `trophy icon png transparent`;
- `gold cup game icon png`;
- `cartoon trophy png`.

### `cube.png`

Иконка кубика прогресса для открытия обычного бокса.

Это может быть именно куб/кристалл/жетон прогресса, не кубок.

Что должно быть:

- маленький кубик;
- кристалл;
- фрагмент прогресса;
- токен.

Параметры:

- `128x128 px`;
- прозрачный фон;
- цвет лучше голубой, фиолетовый или зеленый, чтобы отличался от монет и кубков;
- используется в прогрессе `0/30` для открытия бокса.

### `hp.png`

Иконка здоровья.

Что должно быть:

- сердце;
- аптечка;
- плюсик здоровья;
- красный health-symbol.

Параметры:

- `128x128 px`;
- прозрачный фон;
- основной цвет: красный / розовый;
- используется в карточке бойца и в бою рядом с HP.

### `damage.png`

Иконка урона.

Что должно быть:

- меч;
- кулак;
- взрыв;
- прицел;
- молния;
- острый удар.

Параметры:

- `128x128 px`;
- прозрачный фон;
- основной цвет: оранжевый / красный / желтый;
- используется в карточке бойца рядом с уроном.

### `level.png`

Иконка уровня персонажа.

Что должно быть:

- стрелка вверх;
- звезда уровня;
- шеврон;
- значок level up;
- маленькая медаль.

Параметры:

- `128x128 px`;
- прозрачный фон;
- лучше синий, фиолетовый или золотой цвет;
- используется рядом с текстом уровня бойца.

### `crit.png`

Иконка критического шанса.

Что должно быть:

- молния;
- красный прицел;
- вспышка;
- значок критического удара;
- острый burst/star.

Параметры:

- `128x128 px`;
- прозрачный фон;
- должна выглядеть опасно/энергично;
- используется в карточке бойца и магазине улучшений.

### `click.png`

Иконка силы клика.

Что должно быть:

- палец;
- курсор;
- кнопка с нажатием;
- hand tap icon.

Параметры:

- `128x128 px`;
- прозрачный фон;
- используется в магазине улучшений для силы клика.

### `passive.png`

Иконка пассивного дохода.

Что должно быть:

- часы + монета;
- монета со стрелкой;
- автоматический доход;
- idle/profit symbol.

Параметры:

- `128x128 px`;
- прозрачный фон;
- используется в магазине улучшений для пассивного дохода.

## Кнопки меню

Для кнопок-иконок лучше использовать квадратные PNG `128x128 px` с прозрачным фоном. Это должны быть именно иконки, не целые кнопки с текстом.

### `settings.png`

Иконка настроек:

- шестеренка;
- желательно белая/синяя/фиолетовая;
- используется на кнопке настроек.

### `profile.png`

Иконка профиля:

- силуэт игрока;
- аватар;
- карточка пользователя;
- используется для окна статистики.

### `fighters.png`

Иконка бойцов / коллекции:

- несколько персонажей;
- карточки;
- маска/герой;
- используется для окна коллекции бойцов.

### `leaderboard.png`

Иконка лидерборда:

- пьедестал;
- список рейтинга;
- трофей с таблицей;
- используется для таблицы лидеров.

### `shop.png`

Иконка магазина:

- тележка;
- магазин;
- ценник;
- используется для покупки персонажей или офферов.

### `upgrade.png`

Иконка улучшений:

- стрелка вверх;
- гаечный ключ;
- молния апгрейда;
- используется для магазина улучшений.

### `vip.png`

Иконка VIP:

- корона;
- алмаз;
- золотой VIP badge;
- используется для VIP-оффера и статуса.

## Боксы

### `box.png`

Обычный бокс за 30 кубиков прогресса.

Что должно быть:

- яркий сундук;
- loot box;
- коробка с наградой;
- можно с замком или сиянием.

Параметры:

- лучше `256x256 px`;
- прозрачный фон;
- должен выглядеть как награда, которую хочется открыть;
- используется в кнопке обычного бокса.

### `ad-box.png`

Бокс за rewarded-рекламу.

Что должно быть:

- похож на обычный бокс, но с отличием;
- можно добавить значок play/video;
- можно сделать другой цвет.

Параметры:

- лучше `256x256 px`;
- прозрачный фон;
- визуально отличается от `box.png`;
- используется для рекламного бокса.

## Фоны интерфейса

Фоны могут быть PNG с непрозрачным или полупрозрачным фоном.

### `panel-bg.png`

Фон больших окон: профиль, настройки, коллекция, лидерборд.

Параметры:

- рекомендуемый размер: `512x512 px` или `1024x512 px`;
- можно с закругленными углами;
- лучше без текста;
- должен хорошо растягиваться;
- стиль: темная/синяя/фиолетовая панель с обводкой.

### `button-bg.png`

Фон кнопок.

Параметры:

- рекомендуемый размер: `256x128 px` или `512x256 px`;
- закругленная кнопка;
- без текста;
- яркий градиент;
- можно с обводкой и бликом.

### `card-bg.png`

Фон карточек персонажей и строк лидерборда.

Параметры:

- рекомендуемый размер: `256x320 px` для карточки или универсальный `512x512 px`;
- без текста;
- место для иконки и характеристик;
- можно с рамкой редкости.

### `background.png`

Фон главного меню.

Параметры:

- рекомендуемый размер: `1920x1080 px`;
- можно больше, но не меньше `1280x720 px`;
- без важных мелких деталей по краям;
- должен нормально смотреться при 16:9 и 9:16;
- стиль: яркий игровой фон, арена, небо, город, абстрактный мемный фон.

Важно:

- не вставлять в фон кнопки, текст, логотипы и персонажей, которые должны быть отдельными элементами;
- фон будет масштабироваться и обрезаться под разные экраны.
