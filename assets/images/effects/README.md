# Effect Images

Здесь лежат PNG-изображения для боевых и merge-эффектов.

Общие требования:

- формат: PNG;
- фон: прозрачный;
- стиль: яркий, мультяшный, juicy, хорошо читается на темном и цветном фоне;
- без текста внутри картинки;
- желательно без черной/белой квадратной подложки, только сам эффект;
- если картинка большая, игра потом сможет масштабировать ее вниз.

## `bullet.png`

Пуля / снаряд для автобоя.

Что должно быть на картинке:

- маленький летящий снаряд, энергия, шарик, лазерный заряд или мультяшная пуля;
- направление лучше слева направо;
- можно добавить легкий светящийся хвост.

Параметры:

- рекомендуемый размер: `32x32 px` или `64x64 px`;
- прозрачный фон;
- центр объекта должен быть примерно по центру картинки;
- не делать слишком много мелких деталей, потому что пуля будет быстро лететь.

Искать можно по смыслу:

- `cartoon bullet png transparent`;
- `energy projectile png transparent`;
- `game bullet icon transparent`.

## `merge.png`

Эффект слияния двух одинаковых бойцов.

Это НЕ персонаж и НЕ кнопка. Это отдельная вспышка/магический эффект, который появляется в момент merge.

Что должно быть на картинке:

- вспышка;
- звезды;
- круг энергии;
- сияние;
- магический взрыв без дыма;
- частицы вокруг центра.

Параметры:

- рекомендуемый размер: `128x128 px` или `256x256 px`;
- прозрачный фон;
- эффект должен быть круглым или радиальным, чтобы хорошо смотрелся вокруг персонажа;
- центр эффекта должен быть в центре картинки;
- лучше выбирать светлые цвета: желтый, голубой, фиолетовый, белый;
- не должно быть букв, цифр, рамок или фона.

Где используется:

- когда игрок перетаскивает двух одинаковых бойцов друг на друга;
- в момент появления бойца следующего уровня;
- можно рисовать поверх персонажа на 0.3-0.6 секунды.

Искать можно по смыслу:

- `magic burst png transparent`;
- `star burst effect png`;
- `merge effect game png`;
- `level up sparkle png transparent`.

## `cartoon.png`

Эффект попадания / взрыва в бою.

Это картинка для момента, когда пуля долетела до врага и нанесла урон.

Что должно быть на картинке:

- маленький мультяшный взрыв;
- ударная вспышка;
- дымок с огнем;
- impact-эффект;
- comic hit effect.

Параметры:

- рекомендуемый размер: `128x128 px` или `256x256 px`;
- прозрачный фон;
- эффект должен быть читаемым даже при быстром показе;
- центр взрыва должен быть в центре картинки;
- лучше выбирать оранжевый, желтый, красный или белый цвет;
- не нужен реалистичный большой пожар, лучше короткий игровой impact.

Где используется:

- при попадании пули по врагу;
- при критическом ударе можно масштабировать картинку больше;
- можно показывать 0.2-0.4 секунды.

Искать можно по смыслу:

- `cartoon explosion png transparent`;
- `hit impact effect png`;
- `comic explosion png`;
- `game impact effect transparent`.
