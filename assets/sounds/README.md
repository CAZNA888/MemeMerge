# Sounds

Здесь лежат звуки игры. Все файлы уже добавлены под нужными именами.

## Файлы

- `bg-music.mp3` - фоновая музыка для меню/игры, зацикливается через `loop`.
- `click.wav` - короткий звук клика по игровой зоне.
- `shoot.wav` - звук выстрела/пули в автобою.
- `merge.wav` - звук слияния двух одинаковых бойцов.
- `box.wav` - звук открытия бокса.
- `win.wav` - победный звук после боя.
- `lose.wav` - звук поражения после боя.
- `button.wav` - короткий звук нажатия UI-кнопки.

## Как выбирать замену

Если будешь менять звуки:

- короткие эффекты лучше держать в `.wav`;
- музыку лучше держать в `.mp3` или `.ogg`;
- короткие UI-звуки должны быть 0.05-0.3 секунды;
- выстрел, merge и бокс должны быть 0.2-1.0 секунды;
- победа/поражение могут быть 1-3 секунды;
- громкость у всех файлов должна быть примерно одинаковой, без резкого перегруза.
